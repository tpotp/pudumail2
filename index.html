Pudu Mail - Attachment Explorer

🇨🇱 PRODUCTIVITY TOOL FOR GMAIL

Pudu Mail - Attachment Explorer is a client-side productivity tool designed to help you inspect, sort by size, and manage Gmail attachments to free up Google storage space.

🔒 100% Client-Side & Private: Runs entirely in your browser. Email data and attachments never leave your device.

⚖️ Sort by Size Largest videos & files first
📥➡️🗑️ Download & Trash Save to PC and free up space
📦 ZIP Export Batch download multiple files

📋 Application Purpose & Features / Propósito de la Aplicación

1. App Functionality & Purpose / ¿Qué hace Pudu Mail - Attachment Explorer?

Pudu Mail - Attachment Explorer is a web productivity tool that allows Gmail users to inspect, sort, and manage their email attachments (photos, videos, audio, PDF documents, and archives) ordered from largest to smallest, making it effortless to identify large files and free up Google Cloud storage space.

2. Google API Permissions / Justificación de Permisos Solicitados
  • https://www.googleapis.com/auth/gmail.readonly: Used strictly to read email attachment metadata, filenames, and file sizes to render local previews in the browser. No email body text or user data is sent to any external server.
  • https://www.googleapis.com/auth/gmail.modify: Used solely when the user explicitly requests to move a specific email containing downloaded attachments to the Gmail Trash to free storage space.
3. Data Protection & Limited Use / Privacidad y Seguridad

This application operates 100% on the client side (Client-Side Single Page App) inside the user's web browser. We do not store, transfer, or share user data with third parties or external databases. Pudu Mail - Attachment Explorer's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
